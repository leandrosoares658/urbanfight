# Urban Fight — site

React + Vite + React Router.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # gera /dist
```

- Textos, preços e horários: `src/data/site.js`
- Imagens: `public/img/` (veja `public/img/LEIA-ME.txt`)
- WhatsApp e Instagram: `src/data/site.js` → `contato`
